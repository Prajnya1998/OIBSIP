# Retail Sales Exploratory Data Analysis (EDA)

## Internship
Oasis Infobyte – Data Analytics Internship

## Project Overview
This project explores a retail sales dataset to identify sales trends, customer demographics, product category performance, and relationships between numerical variables.

## Dataset
- **File:** `Retail_Sales_Dataset.csv`
- **Records:** 1,000 transactions
- **Columns:** 9
- **Missing values:** None

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
1. Dataset loading and inspection
2. Descriptive statistics
3. Monthly and quarterly sales trends
4. Customer age-group and gender distribution
5. Product category revenue and quantity analysis
6. Correlation analysis and heatmap
7. Revenue comparison by gender

## Key Findings
- Electronics generated the highest revenue: 156,905.
- Clothing generated 155,580 in revenue.
- Beauty generated 143,515 in revenue.
- Female customers contributed 232,840 in revenue.
- Male customers contributed 223,160 in revenue.
